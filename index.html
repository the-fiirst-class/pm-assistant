项目简介

芯片研发项目周期长、环节多、跨团队协同密集。风险信号分散在日常沟通里，发现与处置之间常常断开，项目经理的判断也难以沉淀为可复用的经验。

本项目把分散的风险信号汇聚为结构化条目，由智能体完成分级与影响分析，再由项目经理作出判断，依据与结论统一回流数据底座，形成可追溯的决策闭环。

系统构成

智能体技能层

十八份技能文档，覆盖风险编排、判断反馈、信号扫描、影响分析、会议纪要、周期巡检等能力。风险编排是唯一分析中心。

可视化指挥舱

组合视图呈现项目状态、决策队列、团队负载与风险分布；项目详情呈现节点进度、风险清单与判断入口。

统一数据底座

风险表保存最新状态，判断反馈表只追加保存历史，两张表构成单一真相源，两个入口共用。

数据流

项目事件　→　风险编排　→　规则 / 案例 / 影响分析　→　风险条目　→　PM 判断　→　判断沉淀

核心能力

风险感知与分级

读取项目事件，命中确定性规则后生成风险条目，给出风险等级、依据摘要、影响节点与建议动作。事件只记录客观事实，分析过程可解释。

判断闭环

确认、驳回、稍后处理、标记误报四种判断都必须填写依据，不足五个字拒绝提交。判断提交后，最新状态与历史记录同时更新，只有确认动作触发后续协同。

双入口一致

指挥舱与协作卡片共用同一套校验、幂等与写回逻辑，任何一端的判断都会在另一端即时可见，不出现两套台账。

技术实现

层次技术选型
前端React 19、Vite 7、TypeScript 5，哈希路由，构建产物为纯静态资源
后端Node.js 内置 HTTP 与 SQLite 模块，零第三方运行时依赖，一条命令启动
可靠性幂等键去重、判断依据校验、状态守卫、写回即重建快照、后端不可达时前端降级
验收端到端契约验证脚本，三十九项断言全部通过
